Unidad 1

¿Qué es Python y para qué sirve?

¡Bienvenido al mundo del código!

Python es un lenguaje de programación muy popular, famoso por ser fácil de leer y escribir. No usa reglas raras ni palabras complejas, por lo que se parece mucho a hablar en inglés.

¿Dónde se usa? Grandes empresas como Google, Instagram y sistemas de Inteligencia Artificial lo usan todos los días para automatizar tareas, ordenar bases de datos y hacer que las computadoras trabajen solas.

Unidad 2

Lógica Computacional y Diagramas de Flujo

Dibuja tus ideas antes de programar

Un algoritmo es solo una lista ordenada de pasos para solucionar un problema (como una receta de cocina). El diagrama de flujo es el dibujo de esa receta.

Los bloques principales son:

  • Rectángulos: Para acciones o pasos comunes.
  • Rombos: Para hacer preguntas de SÍ o NO (decisiones).
  • Flechas: Indican el camino que sigue la información.
Unidad 3

Mostrar información en la pantalla (print)

La función de salida básica

Para que la computadora te muestre un mensaje en la terminal de Spyder, usamos el comando print(). Todo lo que quieras escribir dentro de los paréntesis debe llevar comillas a los lados.

Las palabras sueltas o frases se llaman textos o strings (str). Recuerda abrir y cerrar los paréntesis y las comillas correctamente para que no te salga error.

Trabajar con Números Enteros y el Teclado

Guardar números y pedir datos ⌨️

Las variables de tipo int sirven para guardar números enteros (como 10, 50 o 2026) sin decimales. Si quieres que el usuario escriba un dato desde el teclado, usamos el comando input().

Un truco importante: Todo lo que escribes por teclado entra como texto. Si quieres hacer matemáticas con ese dato, debes obligar a la computadora a transformarlo en número envolviéndolo así: int(input()). A esto se le llama conversión o Casting.

Unidad 5

Trabajar con Números Decimales (Float) y Matemáticas

Números con punto y operaciones

Para guardar números que llevan decimales (como las notas con promedio o los precios), usamos el tipo de dato float. En Python nunca usamos la coma, siempre se pone un punto (.) para marcar los decimales.

Los símbolos matemáticos en código son:

  • Suma (+) y Resta (-).
  • Multiplicación (*) y División (/).
  • Potencia o elevar un número (**).

Unidad 6

Tomar Decisiones en el Código (if - else)

Hacer preguntas lógicas

Para que tu programa tome caminos diferentes según la situación, usamos el comando if (que significa "Si pasa esto..."). Si la pregunta es verdadera (True), se hace el código de adentro.

Si la pregunta es falsa (False), el programa salta al bloque else (que significa "Si no...").

Dos reglas de oro: Siempre debes poner dos puntos (:) al final de la pregunta y dejar 4 espacios vacíos (sangría) al empezar las líneas de adentro para que Python sepa qué orden obedece.

Práctica de Aula (Módulo 6)

Nivel 1: Fácil
Nivel 2: Intermedio
if edad >= 18:
print("Mayor")
otherwise:
print("Menor")
Nivel 3: Avanzado
Nivel 4: Reto Supremo
Unidad 7

Repetir Acciones en el Código (while)

Bucles que dependen de una condición 🔄

El comando while (que significa "Mientras pase esto...") sirve para repetir un bloque de código muchas veces de forma automática. El ciclo se va a seguir ejecutando en la pantalla siempre y cuando se cumpla la condición planteada.

Práctica de Aula (Módulo 7)

Nivel 1: Fácil
Nivel 2: Intermedio

while numero < 3:
print(numero)

Nivel 4: Reto Supremo
Unidad 8

Contar Vueltas Exactas en el Código (for)

Repeticiones con un límite fijo 📐

El comando for sirve para repetir un bloque de instrucciones cuando ya sabes de antemano el número exacto de vueltas que necesitas dar (por ejemplo, repetir algo exactamente 5 o 10 veces).

En Python, trabaja de la mano con el comando range(), que se encarga de fabricar una lista oculta de números. La gran ventaja del bucle for es que la variable de control avanza sola; no necesitas sumarle nada manualmente al final de cada vuelta.
